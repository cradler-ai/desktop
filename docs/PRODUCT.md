# Cradler Desktop（AI 扩展管家）

给普通人用的 AI 扩展安装器：复制一个 GitHub 地址、一条安装命令或一段配置，就能把 skill、MCP、插件装进 Claude、Cursor、Codex 等应用。

## 要解决的问题（来自 owner 自己的经历）

1. 拿到别人在 GitHub 上开源的项目，不会装，怕装错，还要下载东西。
2. 分不清远程（在线服务）和本地（装在本机）有什么区别。
3. 装完有时候不能用也不知道，后来才知道要重启应用。
4. MCP 经常报错，不知道为什么错，也不知道怎么修。

期望的体验：复制仓库地址或别人给的命令（或者拖入下载好的文件夹），界面上直接显示识别出来的东西，点一下按钮就装到各个应用里。

## 产品原则

- 用户永远不碰终端、不看 JSON、不自己装 Node。
- 远程 / 本地这类技术概念由应用判断，界面只用一句人话解释：「在线服务」「装在本机」。
- 别人给的命令不直接执行：先拆开看清它要装什么、装到哪，显示出来等用户确认。
- 每次写入前备份，可以一键撤销。
- 装完自己先连一次测试；需要重启的应用直接给重启按钮。
- 报错翻译成中文，能自动修的给修复按钮。
- 能走官方通道就走官方通道（Claude 桌面版有 .mcpb 就让它自己装，Cursor 用官方安装链接）。
- 不发明新格式：MCPB manifest、MCP Registry server.json、SKILL.md、Claude 插件市场格式。

## 界面风格

黑白分明 + 毛玻璃，两个都要（owner 2026-11-12：先嫌灰色多「很难看」，改成纯白后又问「毛玻璃怎么没有了」）：
- 窗口本身是原生毛玻璃（tauri.conf.json：`fullScreenUI` 材质，`state: active`，失焦时也不变成灰色实底）。
- 各层都是半透明白：侧栏最通透，主区域偏白，卡片和输入框是更白的磨砂层；不要再用不透明的纯白把玻璃盖住。
- 选中、主按钮、勾选、开关一律黑底白字；颜色只用于状态：绿＝正常，红＝有问题，琥珀＝提醒。
- 玻璃透出的是窗口后面的东西：后面是灰白色窗口时会偏灰，放在彩色壁纸上才最明显。
- 大圆角，无描边、无投影、无分割线、无 emoji，层级只靠底色和间距；系统字体。

## 现在的进度（2026-11-12）

- 安装：粘贴即识别；skill 直接下载进 Claude Code / Codex 的技能文件夹（同名旧版移到废纸篓）；MCP 写进 Claude Code（官方命令）、Cursor / Claude 桌面版 / Gemini（JSON，保留原格式）、Codex（TOML）；插件走 `claude plugin`；装完自动测一次连接；Claude 桌面版给「立即重启」。
- 已安装：读 5 个应用的 MCP（含项目级、插件自带的）、所有技能目录（含账号同步、符号链接）、Claude 插件；标出「各处配置不一样」「内容不一样」；插件可启停，技能可移到废纸篓。
- 体检：逐个真实启动/连接 MCP，报错翻译成大白话；能修的给「修复」按钮（拆开写在一起的命令、填密钥、改成自动下载运行、改地址、安装 Node/uv、删掉这条配置），确认后写回原处并自动重新检查；检查运行环境和配置文件格式。
- 编辑：技能文件（SKILL.md 等）、单个 MCP（表单）、整个配置文件（保存前校验语法）都能在应用里打开修改，保存即写回、先备份；`~/.claude.json` 只能逐项改。
- 多语言：跟随系统语言，中文系统显示中文，其他显示英文。
- 每次写配置前自动备份到 `~/Library/Application Support/ai.cradler.desktop/backups/`。
- 还没做：同步到其他应用、签名公证、Windows、更多语言。

## 竞品（2026-11 调研）

都是给开发者的工具，没有面向普通人的：CC Switch（主业是切换 API 供应商，不管 Cursor）、Claude Code Tool Manager（无 LICENSE 文件）、Skills Manager（只管 skill）、vercel-labs/skills（命令行）。借鉴代码只从 MIT 项目拿。
